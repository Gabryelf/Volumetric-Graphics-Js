

## **Название issue:** 
### Реализация системы коллизий и удаления астероида при столкновении с кораблём

---

## **Описание:**

Была реализована система обнаружения столкновений между космическим кораблём и астероидом с последующим удалением астероида из сцены.

---

## **Изменения в коде:**

### **Метод `handleCollision()` - обработка столкновения**

```javascript
handleCollision() {
    // Строка 1: Проверяем, существуют ли оба объекта (корабль и астероид)
    // Если хотя бы один из них отсутствует, выходим из метода, чтобы избежать ошибок
    if (!this.ship || !this.asteroid) return;

    // Строка 2: Проверяем, не происходит ли уже обработка коллизии
    // Это предотвращает множественные срабатывания при одном столкновении
    if (this.isColliding) return;
    
    // Строка 3: Устанавливаем флаг коллизии в true
    // Блокируем возможность повторной обработки этого же столкновения
    this.isColliding = true;
    
    // Строка 4: Создаём временную переменную для хранения позиции астероида
    // Метод clone() создаёт независимую копию вектора позиции
    const tempPos = this.asteroid.position.clone();
    
    // Строка 5: Задаём величину отступа между объектами
    // Значение 1.5 определяет расстояние, на которое разойдутся объекты
    const offset = 1.5;
    
    // Строка 6: Копируем позицию корабля в позицию астероида
    // Астероид "телепортируется" на место, где был корабль
    this.asteroid.position.copy(this.ship.position);
    
    // Строка 7: Сдвигаем астероид вправо по оси X на величину offset
    // Создаём расстояние между объектами, чтобы они не перекрывались
    this.asteroid.position.x += offset;
    
    // Строка 8: Копируем сохранённую позицию астероида в позицию корабля
    // Корабль "телепортируется" на место, где был астероид
    this.ship.position.copy(tempPos);
    
    // Строка 9: Сдвигаем корабль влево по оси X на величину offset
    // Окончательно разводим объекты в разные стороны
    this.ship.position.x -= offset;
    
    // Строка 10: Добавляем визуальный эффект - вращаем корабль вокруг оси Z
    // Значение 0.3 радиан создаёт эффект удара или столкновения
    this.ship.rotation.z += 0.3;

    // Строка 11: Удаляем астероид из сцены
    // Получаем текущую сцену через SceneManager и удаляем модель астероида
    this.sceneManager.getScene().remove(this.asteroid);
    
    // Строка 12: Обнуляем ссылку на астероид
    // Теперь переменная asteroid указывает на null, объект помечен для сборки мусора
    this.asteroid = null;

    // Строка 13: Устанавливаем таймер для сброса флага коллизии
    // Используем setTimeout для задержки перед разблокировкой
    setTimeout(() => {
        // Строка 14: Сбрасываем флаг коллизии через 100 миллисекунд
        // Это позволяет обрабатывать следующие столкновения
        this.isColliding = false;
    }, 100); // Задержка в 0.1 секунды
}
```

---

### **Метод `checkCollisions()` - проверка всех коллизий**

```javascript
checkCollisions() {
    // Строка 1: Проверяем условие столкновения, вызывая метод checkCollision()
    // Метод checkCollision() возвращает true, если объекты пересекаются
    if (this.checkCollision()) {
        
        // Строка 2: Если столкновение обнаружено, вызываем метод его обработки
        // Здесь происходит всё: отталкивание, эффекты и удаление астероида
        this.handleCollision();
    }
    else {
        // Строка 3: Если столкновения нет, сбрасываем флаг коллизии
        // Это важно для корректной работы при повторных столкновениях
        // Без этого флаг мог бы остаться в true после предыдущих проблем
        this.isColliding = false;
    }
}
```

## **Дополнительные изменения (в других методах):**

### **В методе `checkCollision()` (используется для обнаружения):**

```javascript
checkCollision() {
    // Проверка существования объектов
    if (!this.ship || !this.asteroid) return false;
    
    // Радиус корабля (условная сфера вокруг модели)
    const shipRadius = 1.0;
    
    // Радиус астероида (условная сфера вокруг модели)
    const asteroidRadius = 1.2;
    
    // Вычисляем реальное расстояние между центрами объектов
    const distance = this.ship.position.distanceTo(this.asteroid.position);
    
    // Столкновение есть, если расстояние меньше суммы радиусов
    return distance < (shipRadius + asteroidRadius);
}
```

### **В методе `animate()` (основной цикл игры):**

```javascript
animate() {

    // Двигаем корабль вправо только если нет активной коллизии

    if (this.ship && !this.isColliding) {
        this.ship.position.x += 0.01;

    // Каждый кадр проверяем наличие столкновений
```
