## 🧠 Как это работает

### Два типа камеры

Есть два принципиально разных способа смотреть на 3D-сцену:

| Режим | Как работает | Пример |
|-------|-------------|--------|
| **Орбита** | Камера летает вокруг цели, всегда смотрит на неё | Google Earth, стратегии |
| **От первого лица** | Камера = глаза игрока, смотрит куда повернул | Шутеры, RPG |

### Как двигать камеру в пространстве

Камера имеет **позицию** (где она находится) и **направление взгляда** (куда смотрит).

```
        Y (вверх)
        |
        |    📷 Камера в позиции (0, 2, 5)
        |    👀 Смотрит на (0, 0, 0)
        |
        *----- X (вправо)
       /
      /
     Z (на нас)
```

**Движение вперёд** — это смещение туда, куда смотрит камера:

```javascript
// Вектор "вперёд" для камеры
const forward = new THREE.Vector3(0, 0, -1);
// В Three.js камера по умолчанию смотрит по оси -Z
// Значит "вперёд" = (0, 0, -1)

// Поворачиваем этот вектор туда, куда реально смотрит камера
forward.applyQuaternion(camera.quaternion);

// Теперь forward показывает направление взгляда
// Двигаем камеру в этом направлении
camera.position.addScaledVector(forward, speed * deltaTime);
```

### Что такое дельта-время

Если просто прибавлять константу каждый кадр:

```javascript
// ❌ ПЛОХО: при 60 FPS — быстро, при 30 FPS — медленно
position.z -= 0.1;
```

Решение — умножаем на время между кадрами:

```javascript
const delta = clock.getDelta(); // 0.016 сек при 60 FPS, 0.033 сек при 30 FPS

// ✅ ХОРОШО: 5 единиц в секунду на любом компьютере
position.z -= 5 * delta;
```

Формула: `расстояние_за_кадр = скорость × время_с_прошлого_кадра`

## 📝 Разбор ключевых моментов

### OrbitControls

Библиотека, которая сама обрабатывает события мыши и двигает камеру. Нам остаётся только обновлять её каждый кадр:

```javascript
const orbitControls = new OrbitControls(camera, canvas);
// В игровом цикле:
orbitControls.update();
```

**Параметр `enableDamping`** — включает инерцию. Когда бросаешь вращение, камера не останавливается мгновенно, а плавно замедляется. Как колесо с трением.

### Pointer Lock API

В режиме от первого лица курсор нужно "запереть" — иначе мышь упрётся в край экрана и перестанет вращать камеру:

```javascript
// Заблокировать курсор
canvas.requestPointerLock();

// Теперь событие mousemove даёт не координаты, а смещение:
event.movementX  // на сколько пикселей сдвинулась мышь по X
event.movementY  // на сколько пикселей сдвинулась мышь по Y
```

Блокировка снимается по Esc или через `document.exitPointerLock()`.

### Движение относительно взгляда

Ключевая идея: игрок нажимает W, персонаж идёт туда, куда смотрит камера. Не просто "вперёд по Z", а именно по направлению взгляда.

```javascript
// "Вперёд" для камеры = (0, 0, -1) — ось Z в минус
const forward = new THREE.Vector3(0, 0, -1);

// Поворачиваем этот вектор так же, как повёрнута камера
forward.applyQuaternion(camera.quaternion);
// Теперь forward указывает именно туда, куда камера смотрит

// Сдвигаем камеру
camera.position.addScaledVector(forward, speed);
```

### Ограничение взгляда по вертикали

Если не ограничить — игрок сможет смотреть "внутрь себя":

```javascript
euler.x = Math.max(-Math.PI / 2.5, Math.min(Math.PI / 2.5, euler.x));
```

`Math.PI / 2.5 ≈ 1.257 радиан ≈ 72°` — достаточно чтобы посмотреть вниз под ноги и вверх в небо, но не перевернуться.

## 🎯 Что попробовать

1. **Измени чувствительность мыши** — поменяй `0.002` на `0.001` (медленнее) или `0.005` (быстрее)
2. **Измени скорость ходьбы** — поменяй `4` в `moveSpeed = 4 * deltaTime`
3. **Поменяй высоту камеры** в FPS-режиме — `camera.position.set(0, 1.7, 4)` → попробуй `0.5` (как будто ползёшь) или `3` (как великан)
4. **Добавь бег на Shift** — если `keys['shift']`, умножай скорость на 2
